# 🚀 Your Cuber

A modern digital cyber cafe platform developed for **Maa Enterprises (Vasudha Kendra)**.

Your Cuber allows customers to request government and online services from home by uploading required documents, making payments, and tracking application status online.

---

## 🌟 Features

- Modern Dark Professional UI
- Responsive Design
- Customer Dashboard
- Admin Dashboard
- Service Listing
- Service Details
- Track Order Page
- Login System UI
- Contact Page
- FAQ Page
- 404 Error Page
- Professional Navigation
- Beautiful Animations
- Optimized JavaScript
- Mobile Friendly
